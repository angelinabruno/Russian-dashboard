# Russian dashboard

A study dashboard for *Голоса* (Golosa) Book One, Chapters 2–4.

Open `index.html` in a browser. Or turn on GitHub Pages for this repository (Settings → Pages → Deploy from branch → `main`, root) to get a link.

## What's in it

- **Урок 2 · Что у меня есть?** Things, gadgets, colors, weather, possessives, adjective endings, plurals, у меня есть.
- **Урок 3 · Какие языки вы знаете?** Languages, nationalities, present and past tense, the prepositional case, и / а / но.
- **Урок 4 · Образование** School subjects, the "study" verbs, the accusative case, в vs на, prepositional pronouns.

Each chapter has:

- **Flashcards** built from the chapter's word list (Новые слова и выражения), in both directions, with known / not known tracking.
- **Grammar cards** with the textbook's tables, endings marked in red.
- **Quizzes**: 10 questions each, graded on the Russian 5-point scale, including two-word quizzes where you change both the adjective and the noun.

Progress is saved in your browser.
